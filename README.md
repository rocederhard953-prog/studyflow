# StudyFlow — сайт + Telegram-бот + напоминания

## Что есть

- Ручной трекер привычек, статистика, домашние задания, расписание и оценки.
- На сайте раздел «Напоминания»: выбрать часовой пояс, время ежедневной отправки расписания **на завтра**, время ежедневного напоминания о **невыполненном** ДЗ, включить/выключить каждый тип уведомлений.
- Бот отправляет расписание на следующий календарный день, даже если уроков нет. ДЗ не отправляется, когда всё выполнено. Команда `/tomorrow` показывает завтрашнее расписание вручную.
- Уведомления отправляются один раз в день на каждый тип, после успешной отправки. Если бот был выключен в выбранную минуту, уведомление за прошедшее время не догоняется.

## Запуск на хостинге

**Команда установки зависимостей:** `pip install -r requirements.txt`

**Единственная команда запуска сайта и бота:** `python start.py`

`start.py` запускает сайт и Telegram-бота в одном процессе (в отдельных потоках), поэтому они используют одну SQLite-базу. Не запускайте несколько экземпляров `start.py` одновременно: Telegram long polling допускает только один экземпляр бота.

Переменные окружения (в панели хостинга, не в коде):

| Переменная | Значение |
|---|---|
| `APP_PASSWORD` | Надёжный пароль для входа |
| `SESSION_SECRET` | Случайная длинная строка, например `python -c "import secrets;print(secrets.token_hex(32))"` |
| `TELEGRAM_BOT_TOKEN` | Токен бота из @BotFather |
| `DATABASE_PATH` | Путь к **постоянному** файлу базы, например `/var/data/studyflow.db` |
| `COOKIE_SECURE` | `1` для HTTPS |
| `PORT` | Порт хостинга, если предоставляется (по умолчанию 8000) |

**Render:** в архиве есть `render.yaml` и `Procfile`. Для Render с постоянным диском нужен тариф, поддерживающий persistent disk. Без постоянного диска данные SQLite исчезнут при перезапуске/переразвёртывании. Не использовать autoscaling и более одного экземпляра. Бесплатный хостинг с засыпанием не гарантирует отправку уведомлений по времени: нужен постоянно работающий процесс.

## Локально

```bash
pip install -r requirements.txt
export APP_PASSWORD='придумайте-пароль'
export SESSION_SECRET="$(python -c 'import secrets;print(secrets.token_hex(32))')"
export TELEGRAM_BOT_TOKEN='токен-от-BotFather'
python start.py
```

Откройте `http://localhost:8000`, войдите, привяжите бота: раздел Telegram → получить код → отправить `/link КОД` боту в личном чате. Затем настройте раздел «Напоминания». Все настройки сохраняются в базе и переживают перезапуск.

На Windows переменные окружения задаются через PowerShell `$env:APP_PASSWORD="..."` и аналогично для остальных.

## Безопасность и ограничения

Токены, пароль, SQLite-файл и секрет не публиковать в Git. Сайт рассчитан на одного пользователя. Для двух разных серверов SQLite не подходит без общей БД; данный комплект рассчитан на **один постоянно работающий экземпляр**. Время уведомлений определяется выбранным IANA-часовым поясом; время с переходом на летнее/зимнее может быть пропущено или неоднозначно. Времена выполнения задач/статистика старой версии продолжают использовать локальное время сервера.
